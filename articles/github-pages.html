Publish with GitHub Pages

A beginner-friendly overview of hosting a static website online.

What Is GitHub Pages?

GitHub Pages can publish static websites built with HTML, CSS and JavaScript from a GitHub repository. It is useful for portfolios, project demos and documentation.

What You Need

  • A GitHub account.
  • A repository containing your website files.
  • An index.html file in the correct location.

Basic Publishing Steps

  1. Sign in to GitHub and create a repository.
  2. Upload your HTML, CSS, JavaScript and other website files.
  3. Open the repository's Settings.
  4. Select Pages in the settings menu.
  5. Choose the deployment source, branch and folder.
  6. Save and wait for the deployment to finish.
  7. Open the published URL shown in Pages settings.

Test Your Website

Open the published URL and check every page, navigation link, image and contact form. Paths that work on your computer may need adjusting when deployed to a project repository.

Important Limitations

GitHub Pages serves static files; it does not run a traditional server-side backend. Never commit passwords, private API keys or access tokens to a public repository.

Read the official GitHub Pages documentation for current setup instructions.
