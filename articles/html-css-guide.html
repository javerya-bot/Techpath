HTML and CSS: Your First Steps

Understand how a website gets its structure and style.

What Is HTML?

HTML stands for HyperText Markup Language. It defines the structure of web content, including headings, paragraphs, links and images.

What Is CSS?

CSS stands for Cascading Style Sheets. It controls the visual presentation of a page, such as colours, spacing, fonts and layouts.

Your First Example

Create a file named index.html and add this code:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
  <style>
    body {
      font-family: Arial, sans-serif;
      padding: 30px;
    }
    h1 {
      color: rebeccapurple;
    }
  </style>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>I made my first web page.</p>
</body>
</html>

How to Test It

  1. Save the code as index.html.
  2. Open the file in your browser.
  3. Change the heading or colour and refresh the page.

What to Learn Next

Practise links, images, lists, semantic HTML and responsive CSS layouts. Try changing one thing at a time so you can see how the result changes.

Practice task: Add a second heading and a link to a website. Explain to yourself what each HTML tag does.
