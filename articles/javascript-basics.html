JavaScript Basics

Learn about variables and values, two important building blocks of JavaScript.

What Is JavaScript?

JavaScript is a programming language used to add behaviour and interactivity to websites. It can respond to button clicks, update page content and validate form fields.

What Is a Variable?

A variable is a named place to store a value so that your program can use it later. Use const when you do not need to reassign a variable, and let when reassignment is needed.

const siteName = "TechPath";
let lessonsCompleted = 0;

lessonsCompleted = lessonsCompleted + 1;

console.log(siteName);
console.log(lessonsCompleted);

Common Data Types

  • String: Text such as "Hello".
  • Number: A number such as 42.
  • Boolean: true or false.
  • Array: An ordered collection of values.
  • Object: A collection of named properties.

Try It Yourself

Open your browser's developer tools and select the Console tab. Type the example above and press Enter to see the output.

Practice Task

Create a variable containing the name of your favourite programming language. Use console.log() to display it. Then try changing the value and running the code again.

Tip: Use meaningful variable names and read error messages carefully. Test one change at a time.
